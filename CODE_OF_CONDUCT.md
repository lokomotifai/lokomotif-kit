# Code of Conduct

Lokomotif Kit is a public methodology project. The contributor base spans practitioners, enterprise teams, students, and community organizers across Turkey and beyond. The way we treat each other in this repository is a public surface — and one we hold to the same standard as the method itself.

This Code applies to every interaction in issues, pull requests, discussions, code review, and any event organized under the Lokomotif Kit name (online or in person, including Komünite Space).

## Expected behavior

- **Professional conduct.** Treat collaborators as you would in a senior client meeting. Disagreement is welcome; condescension is not.
- **Specific feedback.** Critique work, not people. Reference the line, the schema rule, the test result.
- **Patience with learners.** Practitioners enter the project from different backgrounds. Methodology fluency is something we build together.
- **Cultural and linguistic respect.** Turkish and English contributors work side by side. Turkish names, idioms, and regulatory frames belong here. Do not anglicize or correct unprompted.
- **Disclosure of context.** If a contribution relates to a commercial engagement (Lokomotif AI's or anyone else's), say so. Hidden interests undermine the project.

## Unacceptable behavior

The following are not acceptable and will be acted on:

- Personal attacks, insults, or sustained derogatory remarks.
- Harassment, intimidation, or stalking — public or private.
- Discriminatory comments based on identity (gender, ethnicity, religion, sexual orientation, age, disability, nationality, or any similar dimension).
- Sexualized language or imagery in any project surface.
- Publishing others' private information without explicit permission.
- Persistent disruption of discussions, reviews, or events after being asked to stop.
- Bad-faith arguments designed to exhaust other contributors rather than improve the work.

## Enforcement

The Lead Maintainer is responsible for enforcement. Reports are received at **[kit@lokomotif.ai](mailto:kit@lokomotif.ai)** and treated confidentially.

When a report is received:

1. The Lead Maintainer acknowledges receipt within 2 business days.
2. The matter is reviewed; the reporter is consulted before any public action.
3. A response is decided. Possible actions include: a private warning, a request for a public correction, a temporary suspension from project surfaces, or a permanent ban.
4. The reporter is informed of the outcome.

Severity guides the response. A first lapse in tone is not the same as deliberate harassment. The Lead Maintainer's judgment is final, with the understanding that consistency over time matters more than any single decision.

## Scope

This Code applies wherever the project's name is used:

- This repository and its issues, pull requests, discussions, and reviews.
- Affiliated communication channels (project chat, mailing lists, dedicated Komünite spaces, and similar).
- Events, workshops, and meetups held under the Lokomotif Kit banner.

It does not apply to private interactions outside the project — but if private behavior shapes how someone is treated in project surfaces, the Lead Maintainer may consider it.
